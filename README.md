# PaperMind Research Assistant

An AI-powered research assistant that plans, searches, scrapes, summarizes, and synthesizes comprehensive research reports with inline citations and conflict detection.

## Key Features
- ⚡ 4-Stage Multi-Agent Pipeline (Planner → Search → Scrape → Summarize → Synthesize)
- 💬 ChatGPT-style dark mode conversational interface with interactive sidebar history
- 🚀 Parallel assembly-line processing with concurrency-limited LLM summarization
- 📄 Export research reports to PDF and Markdown
- 🔐 Secure JWT Auth with dual-token refresh bridge
